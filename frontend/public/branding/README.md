# ActionsManager Shield Logo Only

This pack contains ONLY the shield/control-plane logo concept assets.

Included:
- PNG exports
- WebP exports
- ICO favicon
- Apple/Android icon PNGs
- SVG wrappers
- Original shield concept sheet

Important:
The SVG files in this pack intentionally embed the PNG artwork so the files match the generated shield concept visually.
They are not hand-recreated vector approximations.

Recommended files for the site:
- Header/logo: svg/shield-horizontal-transparent.svg
- Sidebar/collapsed icon: svg/shield-icon-transparent.svg
- Favicon: ico/favicon.ico
- Apple touch icon: ico/apple-touch-icon.png
- Web app icons: ico/android-chrome-192x192.png and ico/android-chrome-512x512.png
