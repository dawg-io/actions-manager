🚀 Deploy Environments Input Field Fix

❌ Issue Reported

User: @dawg-io

Problem: "i cant add any text into the input field for the deploy environments. when i type nothing happens. fix the input field to allow a input."

✅ Issue Fixed

Root Cause: The handleChange function in DeployEnvironments.tsx was returning early because setManualEnvironments prop was not passed from the parent component.

🔧 Technical Fix Applied

1. Added Missing Interface:

interface ManualEnvironment {
  name: string;
}

2. Added Missing State in ProjectMgmt.tsx:

const [manualEnvironments, setManualEnvironments] = useState<ManualEnvironment[]>([{ name: "" }]);

3. Passed Props to DeployEnvironments Component:

<DeployEnvironments
  // ... existing props ...
  manualEnvironments={manualEnvironments}
  setManualEnvironments={setManualEnvironments}
/>
