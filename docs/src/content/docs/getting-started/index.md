Install ActionsManager, configure authentication, and start managing your GitHub Actions workflows.

- [Quick Start](getting-started/quick-start.html): get ActionsManager running in under 5 minutes.
- [Installation](getting-started/installation.html): `docker run` and Docker Compose, SQLite or PostgreSQL.
- [GitHub PAT Setup](getting-started/github-pat-setup.html): sign in with a personal access token, no OAuth App required.
- [GitHub OAuth Setup](getting-started/github-oauth-setup.html): configure a GitHub OAuth App for browser-based login.
- [First Workflow Walkthrough](getting-started/first-workflow-walkthrough.html): from PAT sign-in to your first saved workflow draft.
- [HTTPS Configuration](getting-started/https-setup.html): put ActionsManager behind HTTPS for any non-localhost deployment.
- [Product Demo](getting-started/product-demo.html): a complete multi-repository rollout, start to finish.
