ActionsManager provides a comprehensive set of tools for managing GitHub Actions workflows at scale across multiple repositories.

## Guides

- [Projects](features/projects.html): group related repositories and manage their workflows together.
- [Workflows](features/workflows.html): manage workflow files across every repository in a project.
- [Reusable Workflows](features/reusable-workflows.html): manage both sides of reuse, producers and consumers.
- [Reusable Workflow Repository Setup](features/reusable-workflow-repository-setup.html): create a reusable workflow repository and connect callers to it.
- [PR Campaigns](features/pr-campaigns.html): roll out a change across many repositories as coordinated pull requests.
- [Drift Detection](features/drift-detection.html): find repositories that diverge from their managed workflows, and resolve it.
- [Managed Actions](features/managed-actions.html): a shared catalog of third-party actions with their inputs ready to use.
- [Environment Rulesets](features/rulesets.html): keep one repository ruleset and apply it across a project.
- [Backup & Restore](features/backup-restore.html): copy your installation before an upgrade and restore it if needed.
- [Permissions](features/permissions.html): who can see a project, and who can change it.

## Operations

- [Build Detection](features/build-detection.html): detect each repository's build type and suggest workflow templates.
- [Build Metrics](features/build-metrics.html): success rates, durations, queue time and trends for managed workflows.
- [Notifications](features/notifications.html): get emailed when a workflow drifts or a PR campaign needs attention.
