Implementation Details

  • Backend: New function count_project_environments() to count existing environments
  • Backend: New endpoint /api/environments-count to get current count per project
  • Backend: Modified /api/create-environment to enforce 2-environment limit for free accounts
  • Backend: Modified /api/sync-environment to respect limits when syncing to new repositories
  • Backend: Delete operations remain unrestricted for existing environments
  • Frontend: Added real-time count display "Currently using: X/2" for free users
  • Frontend: Disabled input field when limit reached with appropriate messaging
  • Frontend: Added environment count fetching and refresh after operations
  • Frontend: Updated environments.js API with new count function
  • Testing: Comprehensive backend tests for environment counting and limit enforcement
  • User Experience: Consistent behavior with environment variables limits
