ℹ️ Reusable Workflow
This workflow uses workflow_call as the trigger event, making it reusable by other workflows. Configure inputs above to make the workflow parameterized. 
name: build-and-deploy

on:
  workflow_call:
    inputs:
      environment:
        description: 'Target environment for deployment'
        required: false
        type: string
        default: 'staging'

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v5
      
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
      
      - name: Install dependencies
        run: npm install
      
      - name: Build application
        run: npm run build

📋 Implementation Summary

This reusable workflow GUI editor extends the main workflow editor functionality specifically for workflow_call triggers:

  • ReusableEventPicker.tsx: Specialized event picker that only supports workflow_call with input configuration
  • ReusableGUIWorkflowEditor.tsx: Modified GUI editor that uses ReusableEventPicker instead of the full EventPicker
  • Enhanced RXWorkflows.tsx: Updated ReusableWorkflowEditor with GUI/YAML toggle functionality
  • Workflow Conversion Utils: Extended to support workflow_call events and input parameter parsing/serialization
  • Input Management: Support for string, number, boolean, and choice input types with validation
  • Round-trip Safe: Maintains workflow_call structure when switching between GUI and YAML modes
