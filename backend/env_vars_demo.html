Implementation Details

  • Backend: New endpoint `/api/env-vars-count` to get current count per project
  • Backend: Modified `/api/update-env-vars` to enforce 2-variable limit for free accounts
  • Backend: Delete and sync operations remain unrestricted for existing variables
  • Frontend: Added real-time count display "Currently using: X/2"
  • Frontend: Disabled add functionality when limit reached with appropriate messaging
  • Frontend: FIXED: Removed restrictions on editing/deleting existing variables for free users
  • Testing: Comprehensive backend tests for counting and limit enforcement
  • User Experience: Clear messaging about limits and current usage
  • User Experience: IMPROVED: Free users can fully manage existing variables even at limit
🔧 Fix Summary: The issue where free users could not edit or delete existing environment variables when at their 2-variable limit has been resolved. Free users can now fully manage their existing environment variables while creation of new variables remains restricted when at the limit.
