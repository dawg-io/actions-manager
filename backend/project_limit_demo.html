Scenario 4: Backend Error Handling

When a free user tries to create a 4th project via API:

Request: POST /projects/
Response: 403 Forbidden
{
  "detail": "Free accounts can only create up to 3 projects."
}

Frontend Error Message:
"❌ Free plan users can create up to 3 projects. You've reached your limit. Please upgrade to create more projects."

Implementation Details

  • Backend: Enforces limit in POST /projects/ endpoint (403 error when limit exceeded)
  • Frontend: Checks account_type and project count from API response
  • UI Behavior: Disables create button and shows warning for free users at limit
  • Error Handling: Graceful 403 error handling with user-friendly messages
  • Testing: 16 new tests covering all scenarios (backend + frontend)
